# Политика конфиденциальности

Приложение «Рядом» использует геолокацию только для поиска магазинов и метро рядом с пользователем, расчёта времени в пути и отображения карты.

- Координаты отправляются в OpenStreetMap Overpass API и OSRM.
- Избранные места хранятся локально на устройстве пользователя.
- Приложение не продаёт персональные данные третьим лицам.
- Пользователь может отозвать разрешение на геолокацию в настройках телефона.
